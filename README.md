# 🛡️ User Management System

A scalable and secure **User Management System** with authentication, authorization, role-based access control (RBAC), and RESTful API endpoints. Built using **Node.js, Express.js, MongoDB, and JWT authentication**.

---

##   Features

- 🔐 **JWT-based Authentication** – Secure login & signup
- 🛠 **Role-Based Access Control (RBAC)** – Admin, User, etc.
- 🔑 **Secure Password Hashing** – Using **bcrypt.js**
- 📦 **RESTful API** – Clean & modular API structure
- 📄 **MongoDB Database** – Scalable NoSQL storage
- 🛡 **Input Validation & Error Handling** – Secure API endpoints
- 📌 **Environment Variables Support** – Using `.env`
- 📑 **Well-structured Codebase** – Maintainable & scalable
